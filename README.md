# Simple Interest Calculator

## Description
The Simple Interest Calculator calculates the simple interest earned or payable on a principal amount over a specified period at a fixed annual interest rate.

## Formula
Simple Interest (SI) = (Principal × Rate × Time) / 100

Where:
- **Principal (P):** Initial amount of money.
- **Rate (R):** Annual interest rate in percentage.
- **Time (T):** Time period in years.

## Example
Suppose:
- Principal = 1000
- Annual interest rate = 5%
- Time = 2 years

Calculation:

SI = (1000 × 5 × 2) / 100 = 100

**Simple Interest = 100**

## Inputs
- Principal amount
- Annual interest rate
- Time in years

## Output
The calculator displays the simple interest for the given inputs.

## Purpose
This project demonstrates the simple interest formula and provides practice with Git and GitHub repository management.
